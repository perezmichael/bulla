# Bulla Prototype

This is a UI prototype for the Bulla payment system, built with Next.js, Tailwind CSS, and Shadcn UI.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- **Dashboard (/)**: "My Links" table view showing recent payment links and their status.
- **Create Link (/create)**: Form interface to generate new payment links.

## Technologies

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS 3
- **Components**: Shadcn UI (Radix Primitives)
- **Icons**: Lucide React
